核心能力

HLS 播放器内核

基于 hls.js，支持直播 / 点播、倍速、音轨与外挂字幕切换、进度续播、画中画与全屏沉浸模式。

多源聚合首页

把 Jellyfin、Plex、Emby、IPTV、WebDAV 与本地文件汇聚到同一首页，按类型分类、跨源搜索与继续观看。

弹幕与字幕

Canvas 高性能弹幕引擎，支持 SRT / VTT / ASS 外挂字幕，本地字幕自动匹配与手动加载。

Gist 云同步

用 GitHub Gist 在多设备间同步收藏、历史、进度与设置，无需自建服务器，数据归你所有。

TMDB 元数据

自动匹配 TMDB 海报、评分、演员、简介与背景图，WebDAV 裸文件名也能变成电影海报墙。

私密优先

账号密码使用 Electron safeStorage 本地加密，不分析、不追踪、不上传播放数据，第三方源由你自行提供。

Jellyfin Plex Emby Xtream Codes IPTV / M3U WebDAV / NAS 本地文件 自定义 JSON 源
