## 这是什么？

腾格里汗是一款**私人流媒体播放器**，不是视频网站。

它本身**不提供任何电影、电视剧或直播**。你把自己的内容接进来——电脑里的影视、网盘、家里的 Jellyfin/Plex/Emby 媒体库、IPTV 直播——它负责用一个统一、好看的界面帮你播放、搜索、下载和续播。

> 打个比方：它像一台电视，你需要自己接上「天线」（片源）才能看到画面。我们不生产节目，只帮你把节目放好。

第一次使用不知道从哪开始？看 👉 **[5 步新手指南](https://github.com/65tiankehan/tengriqaghan-Opendata/wiki)**

## 能做什么

- 🎬 **统一播放** — 电影、剧集、动漫、综艺、直播，一个界面全搞定
- 📺 **直播电视** — 支持 M3U 和 Xtream 线路，带节目单（EPG）和「正在播出」
- 💾 **离线下载** — 把视频下到本地，没网也能看；删了本地文件还能自动回到在线续播
- 🔍 **跨源搜索** — 一次搜索所有接入的片源
- ☁️ **接你的网盘/媒体库** — WebDAV 网盘、Jellyfin、Emby、Plex 都能接
- 🖼️ **自动匹配海报** — 通过 TMDB 获取封面、剧情和评分
- 🔒 **隐私优先** — 无需注册账号，所有凭据加密保存在你自己的电脑上，不上传服务器

## 支持的片源

| 类型 | 说明 |
|------|------|
| Jellyfin / Emby / Plex | 你自建的家庭媒体库 |
| IPTV (M3U) | 公开或自建的电视频道列表 |
| Xtream Codes | IPTV 服务商提供的账号格式 |
| WebDAV / NAS | 网盘或群晖、威联通等网络存储 |
| 本地文件 | 电脑上的视频 |
| 自定义源 | 自己接入的来源 |

## 安全与隐私

- 🔒 **无需注册账号**，不收集个人数据，不跟踪观看行为
- 🔑 你填入的账号、密码、API Key 使用系统级加密（Windows DPAPI / macOS Keychain）**只保存在本机**
- 🚫 应用不内置任何影视内容，你接入的来源由你自己选择和负责

> 这是一个**免费、闭源、供个人非商业使用**的产品。源码不公开，但我们通过数据本地化、最小权限和清晰的责任边界来保护你的隐私。详见 [安全与隐私](https://github.com/65tiankehan/tengriqaghan-Opendata/wiki/安全与隐私)。

## ⬇️ 下载安装

前往 [**Releases 页面**](https://github.com/65tiankehan/tengriqaghan-releases/releases/latest) 下载最新版。

**当前支持：Windows 10 / 11（64 位）**，下载 `TengriQaghan-Setup-x.x.x.exe` 后双击安装即可。macOS 与 Linux 版本将在后续更新中推出。

> 安装后第一次打开，应用里**还没有内容**——这是正常的。跟着 [新手指南](https://github.com/65tiankehan/tengriqaghan-Opendata/wiki)，三步接上你的第一个片源。最快的体验方式：在「设置 → 片源」里添加公开的 **iptv-org** 直播源，立刻就能看电视直播。
